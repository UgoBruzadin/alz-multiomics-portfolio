# `data/`

```
data/
├── external/                    committed small inputs
│   └── example_ad_sumstats.tsv  offline APOE-region GWAS example (auto-generated)
└── processed/                   git-ignored; created by scripts/00_simulate.py
    ├── pheno.csv
    ├── genotypes.parquet
    ├── expression.parquet
    ├── proteomics.parquet
    ├── snp_info.csv
    ├── causal_genes.csv         ground-truth labels for validation
    └── sex_biased_genes.csv
```

- **`external/`** holds small, committed inputs. `example_ad_sumstats.tsv` is a
  synthetic APOE-region summary-statistics file so coloc/lookups run offline; it
  is regenerated automatically if missing. Real public GWAS sumstats downloaded
  via `scripts/download_sumstats.py` also land here (and are git-ignored because
  they are large).
- **`processed/`** is generated by the simulation script and git-ignored; run
  `make data` (or `python scripts/00_simulate.py`) to (re)create it. The
  simulation is seeded, so it is byte-reproducible.

See [`../docs/data_sources.md`](../docs/data_sources.md) for the public GWAS
summary-statistics sources and the rationale for simulating the cohort.
